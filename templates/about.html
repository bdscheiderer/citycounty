About this website:
This website allows the user to search a database containing information about all cities and counties in Missouri. The data is sourced from the Official Manual published by the Missouri Secretary of State. Currently, the database contains the name, population, and classification of each city and county.

Privacy Notice:
This website does not collect any personal information. To help improve the site, we keep an anonymous log of search terms (date, time, and search criteria only). Like most websites, our hosting provider keeps standard server logs for security and maintenance.

Legal Notice:
This website is for educational and informational purposes, including research for legislative drafting. Verify the information against official sources before relying on it in drafting.
